# Scratchpad (brouillon de travail de l'agent)

Mémoire de travail temporaire : notes d'étapes, état d'une tâche en cours,
listes intermédiaires. **Jetable** : ce dossier est ignoré par git et purgé
par la passe de dreaming (fichiers de plus de 7 jours).

Rien d'important ne doit vivre ici — ce qui mérite d'être gardé va dans
`memoire/lecons/` ou `memoire/propositions/` via les skills.
